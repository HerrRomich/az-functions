# SPA in Angular

## Project Structure
- Organize Angular apps under `packages/examples/frontend` or a similar directory.
- Use Angular CLI for scaffolding and workspace management.

## Best Practices
- Use feature modules for scalability.
- Prefer reactive forms and observables for state management.
- Follow Angular style guide for naming and structure.

## Testing
- Use Jest or Karma for unit testing.
- Place tests alongside components or in a dedicated `__tests__` directory.

## Deployment
- Use Azure Static Web Apps or Azure Blob Storage for hosting.
- Automate builds and deployments via CI/CD pipelines.

# Agent Instructions

This repository's authoritative, repository-wide guidance for AI coding assistants lives in
[`.github/copilot-instructions.md`](.github/copilot-instructions.md). Read it before making any changes.

Additional, more targeted instruction files (applied to specific paths) live under
[`.github/instructions/`](.github/instructions/) — e.g. Git naming conventions, and
`example-backend`-specific structure/REST/logging/init/error-handling rules. Check that folder for any
instructions file whose path pattern matches the files you're about to touch, and follow it in addition to
`.github/copilot-instructions.md`.

> `docs/` is an early, unfinished draft and is **not** authoritative — do not use it as guidance (see the
> note at the top of `.github/copilot-instructions.md`).
